# Iris Flower Classification 🌸

## Objective

Classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

using measurements of their petals and sepals.

## Dataset

The classic Iris dataset was used for this project.

## Models Used

- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)

## Workflow

1. Load and explore the Iris dataset
2. Perform exploratory data analysis
3. Check for missing values
4. Split data into training and testing sets
5. Scale the features
6. Train classification models
7. Evaluate model performance
8. Compare the models

## Results

| Model | Accuracy | Weighted Precision |
|---|---:|---:|
| Logistic Regression | 93.33% | 93.33% |
| Decision Tree | 93.33% | 93.33% |
| KNN | 93.33% | 94.44% |

## Skills Demonstrated

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Exploratory Data Analysis
- Classification
- Model Evaluation

## Conclusion

All three models achieved 93.33% accuracy on the test set. KNN achieved the highest weighted precision among the three models.
